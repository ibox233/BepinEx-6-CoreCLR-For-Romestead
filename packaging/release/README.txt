Romestead BepInEx Mod Loader
============================

This is a Romestead-specific mod loader based on BepInEx 6 for .NET/CoreCLR.
It does not include Romestead game files.

Install on Windows
------------------

1. Open the Romestead install directory.
   In Steam: Romestead -> Manage -> Browse local files.
2. Extract the contents of this archive directly into that directory.
   After extraction, install.bat should be next to Romestead.exe.
3. Double-click install.bat from the Romestead game directory.

   If install.bat is blocked by antivirus or Windows policy, right-click
   install.ps1 and run it with PowerShell instead.
   If PowerShell script execution is blocked, open PowerShell in the extracted
   game directory and run:

   powershell -ExecutionPolicy Bypass -File .\install.ps1

4. Start Romestead through Steam.

Install on Linux
----------------

Linux support is experimental and has not been verified with the full game.

1. Open the Romestead install directory.
2. Extract the contents of this archive directly into that directory.
   After extraction, install.sh should be next to Romestead.runtimeconfig.json.
3. Run:

   chmod +x ./install.sh
   ./install.sh

4. Start Romestead through Steam.

Steam file verification or a Romestead game update may restore the game's
runtime config and remove the loader hook. If BepInEx stops starting after
either of these, run install.bat or install.sh again from the game directory.

After install, BepInEx logs are written to:

   BepInEx\LogOutput.log

Mods
----

Put plugin DLLs into:

   BepInEx\plugins

The config and plugin folders are generated by the loader when needed.

Uninstall
---------

Run uninstall.bat on Windows or uninstall.sh on Linux. It restores the
runtimeconfig backup when available and removes the startup hook. It keeps the
BepInEx folder so user mods and settings are not deleted.

Notes
-----

- Do not launch Romestead.exe directly for normal play. Launch through Steam.
- This package only installs the loader hook into the local game runtime config.
- Steam file verification and game updates can overwrite that hook. If the
  loader stops appearing after either action, run the installer again.
- Linux support is experimental. File logs are more reliable than console
  output there.
- It does not bypass Steam ownership checks and does not include game binaries.
