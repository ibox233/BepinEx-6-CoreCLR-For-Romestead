Romestead BepInEx Mod Loader
============================

This is a Romestead-specific mod loader based on BepInEx 6 for .NET/CoreCLR.
It does not include Romestead game files.

Windows client
--------------

1. Open the Romestead install directory.
   In Steam: Romestead -> Manage -> Browse local files.
2. Extract the contents of the win-x64 archive directly into that directory.
   After extraction, d3d11.dll should be next to Romestead.exe.
3. Start Romestead through Steam.

The Windows client package uses a local d3d11.dll hook. It does not need to edit
Romestead.runtimeconfig.json and does not include install/uninstall scripts.

Linux / Steam Proton
--------------------

Romestead does not currently have a native Linux client build. Linux users run
the Windows client through Steam Proton, so this package also uses the Windows
d3d11.dll hook.

Extract the linux-x64 archive directly into the Romestead game folder. After
extraction, d3d11.dll should be next to Romestead.exe.

The Linux/Proton package does not include install/uninstall scripts and does not
edit Romestead.runtimeconfig.json.

After the loader is active, BepInEx logs are written to:

   BepInEx\LogOutput.log

Mods
----

Put plugin DLLs into:

   BepInEx\plugins

The config and plugin folders are generated by the loader when needed.

Notes
-----

- Do not launch Romestead.exe directly for normal play. Launch through Steam.
- The Windows d3d11 hook is for the client only. It is not used by dedicated
  servers.
- Linux support is experimental. File logs are more reliable than console
  output there.
- It does not bypass Steam ownership checks and does not include game binaries.
